SkillCat Admin - Permissions (V1)
Draft, Nov 20, 2026 (spec version: frontend spec Appendix A)

How to read this:
- Each line is one permission: its key, then what it allows.
- Any permission in a section also lets the admin view that section.
- create_edit always means create and edit together: whoever can create can also edit.
- ★ = high-impact (deletes data, moves money or entitlements, or recomputes users' records).
  Limit these to certain roles.
- Permissions are not limited by Created By, Task Type or Question Bank Category.
- Without a section's view permission, the section is missing from the sidebar and its pages don't open.
- Without an action's permission, the button, menu item or field is shown greyed out.

==============================================================================================================
1. Tasks
==============================================================================================================
tasks.view                          Tasks list, Preview Panel
tasks.create_edit                   Create and edit xAPI, Quiz, Hands-On and Resource Tasks
tasks.paywall                       Turn a Quiz's paywall on or off and set its Price IDs, when creating or
                                    editing. Without it, the paywall fields are greyed out: a new Quiz can
                                    only be created free, and an existing Quiz's paywall can't be changed
tasks.proctoring                    Turn Proctoring on or off on a Quiz, when creating or editing. Without it,
                                    the Proctoring field is greyed out: a new Quiz can only be created without
                                    proctoring, and an existing Quiz's setting can't be changed
tasks.unlock_criteria ★             Unlock completion criteria or pass marks after users have completed the
                                    Task (recomputes their completion)
tasks.visibility                    Make Hidden / Make Visible
tasks.delete ★                      Delete Task

quiz_attempts.grant_revoke ★        Grant Additional Attempts (free or on a paid Quiz), Revoke Access on an

4. Certifications
==============================================================================================================
certs.view                          List, Preview Panel, Who Paid (Certification)
certs.create_edit                   Create (From Scratch, Upload Backup, CSV Upload) and edit Certifications:
                                    details, structure, Access Restrictions; Backup Certification (download);
                                    Mark as Done on Setup status
certs.paywall                       Set the paywall (Free, Non-Consumable, Consumable) and Product IDs, when
                                    creating or editing. Without it, the Paywall step is greyed out: a new
                                    Certification can only be created Free, and an existing one's paywall
                                    can't be changed
certs.deep_link ★                   Edit the Deep Link slug, when creating or editing (the old link stops
                                    working at once). Without it, the slug field is greyed out and the slug
                                    made from the name is used
certs.unlock_criteria ★             Edit locked completion criteria (recomputes users)
certs.visibility                    Make Hidden / Make Visible
certs.archive                       Archive & Replace, its settings, Unarchive
certs.delete ★                      Delete Certification
cert_access.grant_revoke ★          Grant Access (a permanent entitlement) and Revoke Access on a Consumable
content_links.create_edit           Add, edit and remove Content Links

12. Exam Reviews, IDs & Name Changes
==============================================================================================================

                                    Integrity Notes and Past Rejections; View ID and its timeline (Users menu,
